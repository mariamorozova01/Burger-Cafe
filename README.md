# 🍔 Burger Cafe Website

A modern and visually appealing burger cafe landing page with a responsive design, product listings, and promotional sections.

## 🚀 Features

- Clean and modern UI
- Full product menu with images and prices
- Promotional discount section
- Sorting functionality
- Responsive layout for all devices
- Sticky header and footer with navigation
- Smooth scroll-to-top button

- HTML5
- CSS3 / Flexbox
- JavaScript (if applicable)
